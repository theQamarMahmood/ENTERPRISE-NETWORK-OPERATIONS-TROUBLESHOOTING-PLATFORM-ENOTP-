# Enterprise Network Operations & Troubleshooting Platform (ENOTP)

Welcome to the local, on-premises repository for ENOTP. This workspace is structured to support development using Python 3.12 (FastAPI, Celery) and React (TypeScript, Material-UI).

## Project Structure
- `/backend`: Python FastAPI application, Celery workers, and scanning daemons.
- `/frontend`: React SPA dashboard utilizing Material-UI and D3/vis.js topology visualizations.
